# MIA Frontend

Frontend `Next.js` 15 avec `App Router`, `TypeScript`, `Material UI` 7 et traduction FR/EN.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`

## Structure

- `src/app`: routes Next.js
- `src/page`: pages metier
- `src/Components`: shell et design system
- `src/translations`: catalogues et provider i18n
- `src/config`: constantes de routes et configuration du site
